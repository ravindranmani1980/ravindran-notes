Scripts

Every PowerShell script on this site, by topic. Each page explains what the script does, its parameters and examples, and has the full source to copy or download.

SharePoint

SharePoint Server

  • Get-SPFarmInventory

    Builds a CSV inventory of a SharePoint Server farm.

  • Get-SPLargeLists

    Finds lists and libraries that are approaching or over the list view threshold.

  • Get-SPLogsByCorrelation

    Collects ULS log entries for a correlation ID from the whole farm.

  • Get-SPPatchStatus

    Verifies that every server in the farm is on the same SharePoint build after patching.

  • Get-SPServiceMatrix

    Shows which SharePoint services run on which servers, as a matrix.

  • Get-SPSiteStorageReport

    Reports storage, quota use and staleness for every site collection.

  • Invoke-SPPostPatchConfig

    Runs the SharePoint configuration step (PSConfig) on this server after installing an update.

  • Invoke-SPWarmup

    Warms up SharePoint web applications by requesting their pages after an app pool recycle.

  • Set-SPBlobCache

    Shows, enables, disables or flushes the BLOB cache for a web application.

  • Set-SPObjectCacheAccounts

    Shows or sets the object cache super user and super reader accounts for a web application.

  • Test-SPUpgradeReadiness

    Runs Test-SPContentDatabase and produces one readable report for upgrade planning.

SharePoint Online

  • Get-SPOExternalUsersReport

    Lists guest (external) users on every SharePoint Online site that allows sharing.

  • Get-SPOListsNearThreshold

    Finds large lists and libraries in a SharePoint Online site and shows their indexes.

  • Get-SPOSiteInventory

    Tenant-wide SharePoint Online site inventory: storage, sharing, staleness, hubs.

  • Get-SPOUniquePermissions

    Reports where permission inheritance is broken in a SharePoint Online site.

  • Remove-SPOOldFileVersions

    Trims old file versions in a document library, keeping the newest N versions.

  • Restore-SPORecycleBinByUser

    Restores items that one user deleted in a time window (mass-deletion recovery).

Migration

  • Find-MigrationBlockers

    Scans a file share (or any folder) for problems that block or complicate a move to SharePoint Online / OneDrive.

Azure

Inventory and clean-up

  • Find-AzOrphanedResources

    Finds orphaned Azure resources that cost money or clutter: unattached disks, unused public IPs and more.

  • Get-AzVMInventory

    Lists every Azure VM in every subscription you can see, with size, power state, disks, IPs and tags.

Governance

  • Get-AzRoleAssignmentReport

    Reports Azure RBAC role assignments in every subscription and flags the risky ones.

  • Get-AzUntaggedResources

    Lists Azure resources (and optionally resource groups) that are missing required tags.

Network security

  • Get-AzNsgCoverage

    Finds gaps in network security group coverage: subnets and network interfaces with no NSG, and unused application security groups.

  • Get-AzNsgRuleReport

    Reports network security group rules in every subscription and flags the risky ones, such as RDP or SSH open to the internet.

Operations

  • Get-AzBackupCoverage

    Shows which Azure VMs are protected by Azure Backup, and which aren't.

  • Invoke-AzVMPowerSchedule

    Starts or stops (deallocates) Azure VMs that carry a schedule tag. Designed for Azure Automation.

AWS

Inventory and clean-up

  • Find-AwsOrphanedResources

    Finds orphaned AWS resources that cost money or clutter: unattached EBS volumes, unused Elastic IPs, idle load balancers and more.

  • Get-AwsEC2Inventory

    Lists every EC2 instance in every enabled region, with type, state, IPs, volumes, IMDS setting and tags.

Governance

  • Get-AwsIamCredentialReport

    Reports IAM users and the root user from the IAM credential report, and flags the risky ones: no MFA, old or unused access keys.

  • Get-AwsUntaggedResources

    Lists AWS resources that are missing required tags, or have them spelled with the wrong case.

Network and data security

  • Get-AwsSecurityGroupReport

    Reports security group rules in every region and flags the risky ones, such as SSH or RDP open to the internet.

  • Get-AwsS3PublicAccessReport

    Checks every S3 bucket for public access, and reports Block Public Access, policy status, ACLs, encryption and versioning.

Operations

  • Get-AwsBackupCoverage

    Shows which EC2 instances, RDS databases, DynamoDB tables and EFS file systems are protected by AWS Backup, and which aren't.

  • Invoke-AwsEC2PowerSchedule

    Starts or stops EC2 instances that carry a schedule tag. Run it on a schedule from EC2, Lambda or Systems Manager.

Google Cloud

Inventory and clean-up

  • Find-GcpOrphanedResources

    Finds orphaned Google Cloud resources that cost money or clutter: unattached disks, unused static IPs, old snapshots and more.

  • Get-GcpVMInventory

    Lists every Compute Engine VM in every project you can see, with machine type, status, IPs, disks, service account and labels.

Governance

  • Get-GcpIamReport

    Reports risky IAM grants and service account keys in every project: public access, basic roles, outside domains and user-managed keys.

  • Get-GcpUnlabeledResources

    Lists Google Cloud resources that are missing required labels, or have them under a slightly different name.

Network and data security

  • Get-GcpFirewallReport

    Reports VPC firewall rules in every project and flags the risky ones, such as SSH or RDP open to the internet.

  • Get-GcpBucketPublicAccessReport

    Checks every Cloud Storage bucket for public access, and reports public access prevention, uniform access, versioning and soft delete.

Operations

  • Get-GcpBackupCoverage

    Shows which Compute Engine VMs and Cloud SQL instances are protected by backups, and which aren't.

  • Invoke-GcpVMPowerSchedule

    Starts or stops Compute Engine VMs that carry a schedule label. Run it on a schedule from Cloud Scheduler, a VM or a pipeline.
