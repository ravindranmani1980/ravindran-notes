Cost scripts

The PowerShell scripts on this site that find waste and cut cost, gathered from the Azure, AWS and Google Cloud sections.

Scripts by cloud

Each link opens the script's page in its cloud section, with documentation and the full source. Reports are read-only; scripts that make changes support -WhatIf.

Azure

  • Find-AzOrphanedResources

    Finds unattached disks, unused public IPs, detached NICs, empty resource groups and old snapshots across every subscription.

  • Get-AzVMInventory

    Lists every VM with size, power state (including stopped but not deallocated), disks and tags.

  • Get-AzUntaggedResources

    Lists resources missing the tags that cost reports depend on.

  • Invoke-AzVMPowerSchedule

    Starts and stops VMs by a schedule tag, with -WhatIf.

AWS

  • Find-AwsOrphanedResources

    Finds unattached EBS volumes, unused Elastic IPs, old snapshots and other leftovers across profiles and Regions.

  • Get-AwsEC2Inventory

    Lists every EC2 instance with type, state, volumes and tags.

  • Get-AwsUntaggedResources

    Lists resources missing required cost allocation tags.

  • Invoke-AwsEC2PowerSchedule

    Starts and stops EC2 instances by a schedule tag, with -WhatIf; skips Auto Scaling group members.

Google Cloud

  • Find-GcpOrphanedResources

    Finds unattached disks, unused static IPs, old snapshots and more in every project.

  • Get-GcpVMInventory

    Lists every Compute Engine VM with machine type, status, disks and labels.

  • Get-GcpUnlabeledResources

    Lists resources missing required labels.

  • Invoke-GcpVMPowerSchedule

    Starts and stops VMs by a schedule label, with -WhatIf; skips managed instance group members.
