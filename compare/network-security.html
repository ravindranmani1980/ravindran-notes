Network protection compared

Firewall rules, security groups and NSGs; managed firewalls; WAF and DDoS; private access; and admin access without open ports, across Google Cloud, AWS and Azure.

All three clouds protect networks in the same layers: filters on each server, a managed firewall where traffic converges, a web application firewall in front of websites, DDoS protection on public addresses, private access to platform services, and admin access without open ports. The names differ, and so do a few important details, such as where a rule can be set once for the whole organisation.

For the network building blocks themselves, see Networking compared. For a detailed look at the web application firewall layer, starting from Google Cloud Armor, see Cloud Armor, AWS WAF and Azure WAF.

A notable difference: Google Cloud's basic firewall (Essentials) needs no appliance or routing at all, so there's no Google Cloud equivalent of the "hub firewall every packet must route through" until you need IPS or TLS inspection. In AWS and Azure, a managed firewall is always an extra hop you design routing around.
