About

These are the working notes of Ravindran Mani, an IT and cloud operations leader based in Miami, Florida.

The main site, ravindran.in, covers experience and leadership. This site is the practical side: the guides and scripts behind the work, written down so the next person doesn't have to learn them the hard way.

The SharePoint notes cover 2005 to 2024: farm architecture, administration, upgrades, governance, PowerShell automation and migrations to SharePoint Online. The Azure, AWS and Google Cloud notes cover structure, governance, security, operations and cost; hands-on AWS examples are on aws.ravindran.in. FinOps notes are being added.

Using the scripts

The scripts are MIT licensed: use them, change them, share them. Test in a non-production environment first, run reports before anything that changes data, and use -WhatIf where it's supported.
